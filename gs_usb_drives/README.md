# gs_usb 驱动工具包

## 概述

- 这里是 Linux `gs_usb` 驱动工具包总入口，按 Jetson Orin 与 RK3588 两个平台分流。
- 本页只负责帮你选平台和文档入口；具体编译、加载、验证流程保留在各平台目录自己的 `README_zh-CN.md` 或 `README_en.md` 中。

## 文档 / 资源

- [gs_usb_sppe_Orin_NX/README_zh-CN.md](gs_usb_sppe_Orin_NX/README_zh-CN.md) - Jetson Orin 中文说明
- [gs_usb_sppe_Orin_NX/README_en.md](gs_usb_sppe_Orin_NX/README_en.md) - Jetson Orin English notes
- [gs_usb_sppe_RK_board/README_zh-CN.md](gs_usb_sppe_RK_board/README_zh-CN.md) - RK3588 中文说明
- [gs_usb_sppe_RK_board/README_en.md](gs_usb_sppe_RK_board/README_en.md) - RK3588 English notes
- [GitHub / Gitee 覆盖范围说明](https://gitee.com/kit-miao/damiao/blob/master/docs/repository/mirror-scope.md) - 双仓覆盖范围说明

## 快速开始

- Jetson Orin 系列板卡：先看 `gs_usb_sppe_Orin_NX/README_zh-CN.md` 或 `README_en.md`。
- RK3588 系列板卡：先看 `gs_usb_sppe_RK_board/README_zh-CN.md` 或 `README_en.md`。
- 进入对应平台说明后，再按实际内核版本选择子目录并执行编译、加载和验证步骤。
